## Use Case:
Search fresh lead data with full realtime filters.

## Pricing
This is a billable endpoint — you are charged for each result returned. If no results are found, the request is free.

<Tip>Your price decreases automatically as your lifetime spend grows. [Check your current tier and pricing →](https://beta.generect.com/settings/billing)</Tip>
